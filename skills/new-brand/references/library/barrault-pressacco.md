# Barrault Pressacco

- **Name:** Barrault Pressacco (architecture practice)
- **Business:** small architecture, urban planning and research office founded 2009 by Thibaut Barrault and Cyril Pressacco; mostly social housing and public commissions, known for material research (massive stone, hempcrete, bio-sourced insulation, reuse); also teaches, publishes (e.g. books on insulation) and curates exhibitions
- **Place:** Paris (134 rue d'Aubervilliers, Paris 19), France
- **Year:** 2019 (The Brand Identity Oct 2019; Fonts In Use Nov 2019); the website still uses the system in 2026
- **Studio:** République Studio (Paris, art direction and graphic design)

## Brief & business truth
A small, research-minded practice whose work is about materials, construction logic and public housing budgets, not signature forms. Its clients are public housing bodies and developers; its peers read its books and lectures. It asked for "brutalist minimalism" with Helvetica in mind. The identity had to be cheap to run in-house (letters, invoices, lists, website) and to present the office as rigorous and unpretentious.

## Strategy / insight
An architecture office's real graphic output is administrative: project lists, invoices, surfaces in m², addresses. Instead of a logo, make the discipline itself the identity: one typeface, one weight, one size, one leading, everywhere, and let layout do all the work, the way the practice lets structure and material do the work in buildings.

## The idea (one sentence)
There is no logo, only a rule: every word the office produces is set in Union at 9.2 pt on 12.25 pt leading, placed on a strict tabular grid.
**Source:** reversal of category codes (removing the mark and all hierarchy), grounded in the craft of the client (constructional honesty, "form follows" logic).

## Register
Strict minimal / brutalist-administrative (grey-white paper, one small grotesque, tables).

## Category codes used or broken
- Used: Swiss-style grotesque and white space, which architects expect.
- Broken: no symbol, no monogram, no bold wordmark, no size hierarchy at all, no hero photography of buildings on the brand materials. Even headlines and names are the same 9.2 pt as body copy. The invoice is designed as carefully as the cover.

## Mark
- **Type:** none in the conventional sense; the name is the identity, typeset.
- **Construction:** "Barrault Pressacco" in Union Regular, sentence case, with a wide fixed gap (one grid column) before the descriptor "Architecture". On documents the pair sits top-left across two grid columns; on the wordmark card it is simply set larger once for display (the only moment it grows, inferred as a presentation frame, not a system rule).
- **Variants:** none. Small-size behaviour is native because it is already set small.

## Wordmark / lettering
Union by Radim Peško (RP Digital Type Foundry): a deliberately neutral grotesque made by merging Helvetica and Arial, the two most common sans serifs, so it answers the Helvetica brief with a knowing, slightly off version. Regular weight only, sentence case, default tracking, no modified letters.

## Type system
- One face, one weight, one size (9.2 pt), one leading (12.25 pt) for everything in print: names, addresses, invoice tables, publication text.
- Hierarchy only through position: labels in a left column ("De :", "À :", "Objet :", "Date :"), values in the next column; large vertical gaps separate blocks.
- Numbers right-aligned in columns (surfaces "8 590 m²", amounts "12 800,00 €"), French typographic spacing before colons kept.
- Thin hairline rules only inside tables, under column heads and totals.
- Website follows the same logic in screen units: one size, a table index.

## Colour system
- Black type on light grey/off-white uncoated paper (warm grey stock, inferred). No colour palette.
- Grey text (a lighter tint) used on the website to show a project not currently selected (inferred from screenshot).
- Colour comes only from photographs of buildings and objects.

## Device(s) / graphic language
- **Tabular grid:** every document is a table: label column + value columns. The letter, the invoice, the business card and the website all share it, so the office's paperwork looks like a project schedule.
- **Project codes:** each project named by a running number plus three-letter code (e.g. "068 BOB", "027 OBK"), used as the index key on the website and in publications, like drawing numbers.
- **Found-object props:** brand photography stages the stationery with dried, shrivelled fruit (small citrus/gourd-like shapes), one per cover on document covers; a quiet nod to material, decay and reuse (the meaning is inferred; the studio did not explain it publicly).

## Imagery
Architectural photography by named photographers (e.g. Maxime Delvaux, Clément Guillaume, Giaime Meloni): straight, daylight, documentary, construction details and interiors (e.g. timber joinery). Brand shots use soft daylight on grey with a single object. Never: renders as brand imagery, people-posed lifestyle shots, dramatic sunsets.

## Voice
Nearly silent. Factual labels and data: Project / Program / Client / Date / Surface / Location. No slogan, no manifesto on brand materials. French administrative register on documents.

## Applications
Letterhead, invoice, envelopes (DL and C5), business cards, postcard with photograph, notebooks/document covers, publications and booklets, website (a sortable table of all projects with a single image beside it).
**What varies:** only content and the photograph. **What stays fixed:** typeface, weight, size, leading, grid positions, grey paper.

## Guidelines structure
No published guidelines; the rule set is the three numbers (Union, 9.2 pt, 12.25 pt) plus the grid, which is the entire system.

## What makes it ownable
The total absence of scale change. In a category where every firm has a bold logotype, a practice whose name is set at 9.2 pt beside a table of m² values is recognisable precisely by its restraint, and by the project-code index.

## What a generic version would have been
A geometric monogram "BP" built from a square and a line, a bold sans wordmark, a black-and-white website with full-screen hero photography of the best building, and a mood of luxury minimalism.

## Principles it demonstrates
- A rule can be the identity: fix type, size and leading, and consistency becomes the recognisable signature.
- Design the dullest documents (invoice, project list) with the most care; for a service firm they are the brand's most frequent touchpoints.
- Express hierarchy with position and space, not size, when the client's value is rigour.
- Index the work like the discipline does (project numbers and codes) so the brand speaks the trade's own language.
- Answer the brief's reference with a knowing variation (Union for Helvetica), not a copy.
