# Covers

`design.md` still applies; this is what a cover adds.

## The set

The brand's profile picture is in the exported kit (`Profile picture.png`, from its logo used small). Covers are the wide images above or behind it, one per platform the user is on: `facebook-cover`, `linkedin-cover` (a person's page), `linkedin-company-cover`, `x-header`, `youtube-banner`, `bluesky-header`. Make only the ones for platforms the user names or the brief lists.

## What a cover is

- **A background.** The profile picture and the name sit right beside it or over it and carry the brand's mark, so the cover sets the brand's world: its imagery, a pattern from the brand kit, the colours, perhaps one short line.
- **The covered parts.** Each platform hides part of its cover: the profile picture's circle, the buttons, what a phone crops. The presets carry these zones and the checks name them: keep words and anything that matters clear of them.
- **It changes.** A cover is the place for this season, a launch or an offer; say so to the user, and make it easy to remake (a page with its text as values).

## One set, one idea

Covers for several platforms come from one idea composed for each shape: one page whose design declares every cover's format. Covers that exist, for more platforms: the `repurpose` skill.
