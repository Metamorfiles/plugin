# Fonts

Open-licensed families (SIL Open Font License, all on Google Fonts), for a brand created from nothing,
and as stand-ins when a brand's own face can't be used. Every one can be embedded in the images
Studio renders.

## By what they carry

| Role | Families |
|---|---|
| Warm serif display | Fraunces (soft, with a SOFT axis for rounder letters), Young Serif (sturdy, friendly) |
| Sharp serif display | Playfair Display (high contrast), DM Serif Display (bold editorial), Gloock, Instrument Serif (thin, quiet), Bodoni Moda (fashion) |
| Serif for reading | Newsreader, Source Serif 4, Lora, EB Garamond, Libre Baskerville, Crimson Pro |
| Neutral sans | Inter, Work Sans, IBM Plex Sans, Libre Franklin |
| Friendly sans | Manrope, DM Sans, Figtree, Plus Jakarta Sans, Outfit, Nunito Sans |
| Characterful sans | Space Grotesk, Bricolage Grotesque, Syne, Archivo (width axis, from condensed to expanded) |
| Loud and condensed | Anton, Oswald, Barlow Condensed, Big Shoulders Display, Bebas Neue (capitals only) |
| Mono | JetBrains Mono, IBM Plex Mono, DM Mono, Space Mono |
| Handwritten | Caveat |

## Pairings that work

- Fraunces with Inter: craft food, warm shops, calm care.
- Instrument Serif with Inter: quiet, premium, calm.
- DM Serif Display with DM Sans: editorial, confident.
- Playfair Display with Source Sans 3: classic fashion and beauty.
- Newsreader with Manrope: considered, humane tech.
- Space Grotesk with Inter: technical, product-led.
- Bricolage Grotesque with Figtree: playful, young.
- Anton or Barlow Condensed with Barlow: loud promotions, sport, street.
- Young Serif with Work Sans: friendly neighbourhood businesses.

One family in two weights (Archivo, Manrope, Fraunces) is a pairing too, and often the stronger one.

## Stand-ins for licensed faces

The closest open alternative, never the same face. Mark it `proposed` in Sources, name the real face
in Known gaps, and never call the stand-in by the brand's font's name.

| Licensed face | Open stand-in |
|---|---|
| Helvetica, Arial | Arimo (Arial's metrics), or Inter |
| Futura | Jost |
| Gotham, Proxima Nova | Montserrat |
| Avenir | Nunito Sans |
| Circular | DM Sans or Figtree |
| Franklin Gothic | Libre Franklin |
| Acumin Pro Condensed, Trade Gothic Condensed | Archivo Narrow or Barlow Condensed |
| Garamond | EB Garamond |
| Baskerville | Libre Baskerville |
| Caslon | Libre Caslon Text |
| Didot, Bodoni | Bodoni Moda |
| Times | Tinos (Times's metrics) |
| Georgia | Gelasio (Georgia's metrics) |
